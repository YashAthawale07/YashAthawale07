## Featured Projects

### [DocMind](https://github.com/YashAthawale07/Doc_Mind) — AI-Powered Document Intelligence

A full-stack document assistant that lets users upload documents, search by meaning, and ask grounded questions with source citations.

- Built document parsing, text chunking, embeddings, and semantic similarity search
- Implemented a Retrieval-Augmented Generation pipeline with Spring AI and pgvector
- Added chat memory, JWT authentication, and role-based access control
- **Stack:** Java, Spring Boot, Spring AI, React, PostgreSQL, pgvector

### [GeoTracker](https://github.com/YashAthawale07/GeoTracker_Flutter_app) — Location-Based Attendance

A Flutter and Spring Boot attendance system that validates employee check-ins using GPS coordinates and office geofencing.

- Developed role-based experiences for administrators and employees
- Built REST APIs for employee management, attendance, geofences, and reporting
- Added office-hours validation, late-arrival detection, duplicate prevention, and attendance filters
- **Stack:** Spring Boot, Flutter, Dart, MongoDB, Spring Security, JWT

### [Inventory Management System](https://github.com/YashAthawale07/Inventory-Management-System)

A full-stack inventory platform for managing products, categories, stock levels, sales, and reporting dashboards.

- Implemented CRUD operations, validation, error handling, and low-stock alerts
- Built dashboard visualizations and connected the React frontend with backend APIs
- **Stack:** React, Spring Boot, MongoDB, JavaScript
